Rat Lab progression is not a published XP ladder. The official listing describes a per-session tool timer, and the **Out of the Lab** badge describes clearing all three stages. Those two facts are enough to explain the progression structure without copying a numbered level table from another game.

## The Two Verified Progression Systems

| System | Official evidence | What it means |
|---|---|---|
| Escape stages | Out of the Lab: clear all three stages and get outside | A full Lab Rat escape has three stages |
| Session tools | Game description: tools unlock the longer you play; time resets every session | Tool access grows within a session, not as a permanent account level |

The two systems are related but not interchangeable. Clearing a stage is an escape milestone; unlocking a tool is a time-based session event. Neither source publishes a level number, XP requirement, or exact unlock minute.

## What “Three Stages” Means

The badge description supports a three-stage escape objective. It does not name the stages, provide a map, or say that every role experiences them in the same way. A page that lists named chambers and exact routes needs a separate developer source or verified in-game documentation.

For the Lab Rat route we can verify, see [How to Escape](/en/mechanics/rat-lab-escape). The key checkpoints are learning containment, using the bite on a breakable wall, clearing the stages, and reaching the outside.

## Why There Is No Level Table Here

The previous version of this page used a generic difficulty curve and stage tips that were not tied to the Roblox experience. We removed those claims. The official game description and public badge data do not support:

- numbered levels;
- XP or prestige thresholds;
- permanent tool unlocks;
- a “level 4” chamber;
- named bosses or collectible counts.

Those may exist in another game with a similar name, but they are not Rat Lab facts.

## A Practical Progression Plan

1. Join the official experience and choose a role.
2. Observe which tools become available during the session.
3. As a Lab Rat, work toward the three-stage escape.
4. As a Scientist, run an experiment and log a new mutation.
5. As Security, complete a recapture.
6. Use the official badges as checkpoints.

This plan reflects the verified objectives without promising a shortcut or a fixed completion time.
