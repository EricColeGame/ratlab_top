In the Roblox experience Rat Lab, the Scientist is not a generic support class. The official description says Scientists **create their own mutations and test them on lab rats**. Two public badges give the loop concrete checkpoints: run a first experiment on a live subject, and log a mutation nobody had recorded yet.

## The Verified Mutation Loop

| Step | What is verified | What is not verified |
|---|---|---|
| Choose Scientist | The role exists and creates mutations | Exact role-selection screen or keybind |
| Create a mutation | Scientists create their own mutations | Mutation names, tiers, costs or stat values |
| Test it on a rat | The official description names live rat subjects | Damage formulas, duration or cooldown numbers |
| Log a new result | New Specimen is awarded for logging a mutation nobody had recorded | How many mutations exist or which are rarest |

The official source supports the shape of the loop, not a tier list. A page that presents exact mutation percentages without a developer source would be guessing.

## Two Badges That Teach the Loop

### For Science

Roblox describes **For Science** as: “Run your first experiment on a live subject.” This is the entry point for a new Scientist. It confirms that experiments are performed on a live rat subject, not only on static objects.

### New Specimen

Roblox describes **New Specimen** as: “Log a mutation nobody had recorded yet.” This suggests that discovery and record-keeping matter, but it does not establish a complete mutation catalog. Do not assume that a mutation named on another website is official.

## A Practical First Experiment

1. Join the official game as a Scientist.
2. Find the experiment or mutation interface available to your role.
3. Create a mutation and test it on a live rat subject.
4. Record the result you observe rather than relying on an unsourced tier list.
5. Check whether the experiment or mutation has unlocked a badge.

This is intentionally a method, not a recipe. The developer has not published exact recipes, cooldowns, or mutation values in the official description.

## Mutations Are Not Unlockable Heroes

The official listing describes a role-based sandbox, not a roster of heroes that players unlock. A Scientist creates mutations; a Lab Rat is a test subject. Treating mutations as a hero-unlock checklist changes the game's structure and leads to false advice.
